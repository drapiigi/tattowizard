# Preferences

_Last updated: 31 Oct 2026_

## Brand
- Name: **Tattowizard** (working name, may change). Wordmark: "Tatto" + italic accent "wizard", with a small four-point star mark.
- Tagline: *Custom ink, conjured with intent.*
- Fictional business, artists, address and email (`hello@tattowizard.example`). No real business names or logos.

## Design
- Dark editorial look: near-black background, warm off-white text, one accent colour (ember orange `#e2552b`).
- Strong serif headlines (Fraunces), clean sans body (Inter). Generous whitespace, tasteful motion; respects reduced motion.
- Mobile-first and responsive.
- Images: self-hosted, AI-generated, clearly fictional people. No stock images with unclear licences.

## Rules
- Changes go to `dev` first; `main` only after approval.
- Repo `drapiigi/tattowizard` is **public** (approved 31 Oct 2026) so GitHub Pages can serve the preview at https://drapiigi.github.io/tattowizard/ from the `dev` branch root. Never commit secrets or personal data.
- No custom domain, Cloudflare or other hosting without explicit approval.
- Keep `noindex, nofollow`.
- Booking form stays non-functional (no data collection backend) unless approved.
- No inline scripts or styles.
- Keep this file and ARCHITECTURE.md updated.
